## Why it is fast

<CardGrid>
	<Card title="Isolated by the compiler" icon="padlock">
		Every memory access is masked into the instance's own slot. Thousands of instances share one address space,
		and switching between them is a function call.
	</Card>
	<Card title="Instances, not containers" icon="rocket">
		An instance is a memory slot plus shared machine code: kilobytes of RAM, microseconds to start.
		Scale-to-zero is the default.
	</Card>
	<Card title="No control plane" icon="random">
		Desired state spreads by gossip, membership is SWIM, and placement is a pure function every node computes on
		its own. Self-healing falls out of membership changes.
	</Card>
	<Card title="Calls are function calls" icon="forward-slash">
		Service-to-service calls on a node cost 0.45 µs. Across nodes: one authenticated, multiplexed link per peer.
		No DNS, no virtual IPs, no sidecars.
	</Card>
	<Card title="One small binary" icon="download">
		Node, JIT, compiler and CLI ship as one 1.7 MB static binary. A service ships as a module of a few hundred
		bytes.
	</Card>
	<Card title="Linux optional" icon="server">
		The same runtime boots as its own kernel: 694 KB, ready about 3 ms after kernel entry, serving HTTP in 3 MiB
		of RAM.
	</Card>
</CardGrid>

## Write services in Ten

Ten is a small C-like language: typed pointers, structs, `i64` and `f64`, no garbage collector and no runtime.
Its compiler runs in your editor too, so mistakes show up as you type.

<Editor
	file="greet.ten"
	tree={`k10s/
  examples/
    app.k10s
    echo.ten
    greet.ten *
    todo.ten`}
	code={`// greet.ten: answers "hello, <name>" and counts visits.
buffer name: [u8; 64];

export fn handle() {
    heap_reset();
    let n = query_str("name", name, countof(name));
    out_str("hello, ");
    if n > 0 { out(name, n); } else { out_str("world"); }
    let visits = kv_add_int("visits", 1);
    out_str(" (visit #");
    out_int(visits * 1.5);
    out_str(")\\n");
}`}
	diag={{
		line: 11,
		col: 13,
		len: 12,
		message: 'mismatched operand types `i64` and `f64` for `*`',
		help: 'Ten never converts implicitly: use `x as f64` or `y as i64`',
	}}
	caption="The VS Code extension runs the real k10s compiler, built to WebAssembly."
/>
