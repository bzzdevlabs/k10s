| Service | Shows |
|---|---|
| `hello` | the smallest module: one host call |

| `counter` | durable, atomic state with `kv_add`; a one-time migration in `init` |
| `chain` | service-to-service calls, `config`, the `calls` allowlist |
| `todo` | a REST API: path parsing, JSON output, compare-and-swap loops |
| `compute` | CPU-bound work: a SHA-256 chain |
| `nbody`, `sort` | floating point and memory-heavy loops |

## A REST API

`todo` stores items under `item/<id>`, hands out ids with `kv_add`, and keeps an index of live ids that every
instance updates with compare-and-swap loops, so concurrent requests never lose an update.

Ten's SHA-256 takes about 2.5× as long as Go's hand-written assembly, and 1.1–1.6× as long as portable Go: the
baseline JIT keeps at most six locals in registers (ten on arm64) and every memory access pays the mask.
